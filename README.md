# Climate & Financial Risk Analysis Dashboard (South Africa)

## Overview
This project analyzes the financial impact of climate-related events across South African regions and economic sectors. It combines SQL, Python, and dashboard visualization to uncover patterns in climate risk and economic exposure.

---

## Objectives
- Identify regions with the highest climate-related financial losses
- Analyze which sectors are most vulnerable
- Understand the cost impact of different climate events
- Present insights through a visual dashboard

---

## Tools & Technologies Used
- SQL (data querying and aggregation)
- Python (Pandas, Matplotlib for analysis and visualization)
- Looker Studio (dashboard development)
- CSV / Excel (data storage)

---

## Project Structure
- climate_finance_data.csv → dataset  
- queries.sql → SQL analysis queries  
- analysis.ipynb → Python analysis  
- dashboard_screenshots/ → dashboard visuals  

---

## Key Insights
- KwaZulu-Natal shows the highest financial losses due to flooding events  
- Agriculture is the most consistently affected sector  
- Infrastructure damage contributes significantly to economic loss  
- Flood events have the highest average financial impact
